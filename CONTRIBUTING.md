# Contributing

Thanks for your interest! How this project works for now:

- **The original repository is maintained only by its author.** Pull requests are switched off, and changes
  from others are not merged into `main`.
- **Forks are welcome.** Fork the repo and build your own version or branch (other heater brands, an ESP32 box,
  translations...). If it works well, tell us: we're happy to link good forks here.
- **Bug reports and ideas:** open an [Issue](../../issues). Please include your heater's brand and model, the
  Bluetooth name (like `BYD-…`), the phone model, and what you expected to happen.

Where this goes next (license, outside contributions) will be decided later.
